# V7.5 System Dashboard

## 1. 设计目标与接口审计

为首页、使用统计和系统设置提供只读系统状态快照。只调用已有 API，不修改 Agent、Retrieval、Evidence、Provider、Security 或任何 backend 文件，不提供模型切换、Provider 切换或安全配置编辑。

开发前审计结果：

| 已有接口 | 返回信息 | 用途与限制 |
| --- | --- | --- |
| GET `/health` | status、project、version | 仅后端进程健康；不检查模型或 Provider |
| GET `/api/files` | 文件及生命周期、索引状态 | 文件数量、处理数、失败数、已索引数 |
| GET `/api/knowledge-bases` | 知识库列表 | 知识库数量 |
| GET `/api/sessions/{id}/tasks` | 会话任务 | 每个已知会话最多最近 100 项 |
| GET `/api/research-task/{id}` | 状态及保存结果 | 报告和 Evidence 的范围内统计 |

没有公开的 Provider 状态接口、运行配置接口、组件健康接口或全局统计接口。前端不能据此证明 LLM/Embedding/Tavily 已连接，也不能证明 Parser、Index 或向量存储健康。

配置回退边界：项目集成的 Web Search 是 Tavily，页面以静态项目集成信息展示名称，连通性标记未验证。前端进程的环境配置不一定等于后端有效配置，因此不从前端环境推断当前模型，更不读取 `.env`。LLM 模型和 Embedding Provider 显示 Unavailable（无公开配置接口），不是声称后端模型已故障。

## 2. 页面结构

- 首页 `dashboard.py`：保留原概览及快捷工作台，增加“系统状态”选项卡。原报告概览可显示最近系统快照中的报告数。
- 使用统计 `usage.py`：独立页面，展示相同状态与资源统计及范围说明。
- 系统设置 `settings.py`：保留工作空间信息，增加 API 版本、前端阶段、组件状态和统计；只读，无配置输入控件。
- `system_dashboard.py`：共享快照采集和卡片展示，避免三个页面分别实现统计。

初始状态未检查、数量显示 `—`。点击“刷新系统状态与统计”才执行 GET 请求，并显示快照 UTC 时间。切换页面复用浏览器内快照；不声称是持续实时监控。该阶段不新增轮询线程或后端任务。

## 3. 状态来源与含义

- Backend：只有 `/health.status == ok` 显示 Online；失败或其他状态显示 Unavailable。
- Document Pipeline / Parser / Index：健康未验证；另外展示文件记录里的处理、失败和已索引数量，不能用“没有失败文件”推断组件健康。
- Search Provider：Tavily 为项目集成信息，连通性未验证。
- LLM / Embedding：无可用公开配置接口，显示 Unavailable；不猜测实际模型名称，不读取 base URL 或认证参数。
- Vector Database：无健康接口，显示未验证。
- API 版本：只接受 `/health` 返回的三段数字版本号。当前后端 API 版本可能仍为 `0.1.0`，页面明确它不是 Git 标签或 V7 发布版本；前端阶段单独标明 V7.5。

## 4. 统计设计

文件和知识库数量来自各自列表 API，不受文档页筛选影响。文件处理状态按已有 lifecycle/canonical_status 汇总，索引数量按 index_status=indexed 汇总，不新增生命周期。

研究任务范围为当前 session_id 与 V7.2 浏览器历史中已知 session_id 的集合；列表中仅统计 research/async_research，按 task_id 去重。报告按 `(task_id, report_id)` 去重。Evidence 按 evidence_id 去重，仅使用已返回的研究结果，不计入未暴露的运行中证据或所有历史同步聊天。

这些数量不是全局任务总数、完整历史、调用 Token 账单或成本数据。浏览器丢失历史后统计范围可能缩小；每会话最近 100 项也存在明确上限。

成功返回空列表显示 0。接口失败显示 `—`，不使用陈旧成功值替代。任一任务/结果统计读取失败时，研究任务、报告、Evidence 三项均显示未知，避免将部分和伪装成总数；文件和知识库仍可独立显示成功结果。

## 5. 安全限制

不读取 `.env`、API Key、Token、Authorization、Provider base URL、环境变量或 backend 模块。状态收集不持久保存原始响应，只保留固定状态、严格格式化版本、计数与固定错误消息。

健康响应里的任意额外字段被忽略。原始 HTTP 异常消息不展示、不放入快照，防止异常包含认证信息。统计只提取 ID 用于去重，结果快照不保留文档名称、知识库描述、Evidence 内容或报告正文。

本页没有 POST 请求、配置编辑、权限修改、模型试调用、Provider 试调用或安全策略开关。已有聊天/文件页面的功能不在本阶段重构。
