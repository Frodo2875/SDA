# V5.4 Web Safety + Engineering Hardening 开发日志

## 1. 安全风险

开放 Web 来源带来以下程序级风险：

- 搜索摘要或网页正文伪装为系统指令，尝试覆盖 System Prompt；
- 外部文本要求调用、启用或改变 Tool 权限；
- Direct URL 指向 localhost、内网、链路本地地址或云 metadata 服务；
- DNS 解析或重定向将公网域名切换到私网地址；
- 非网页、超大响应、异常编码和异常 HTTP 状态导致不安全失败；
- Trace 缺少 Web 来源、状态与 Evidence 数量，或泄露查询中的隐私数据；
- Web Tool 被当作普通本地只读 Tool，缺少明确的外部访问风险分类。

## 2. 设计方案

### Web Prompt Injection

新增确定性 `web_safety` 检测层，识别：

- Instruction Override；
- System Prompt 引用；
- Tool/Function/Command 执行指令；
- Tool 权限修改指令；
- 高风险 Tool 名称。

检测结果只用于标记，不删除或改写来源正文。所有 `WebSearchResult`、
`WebDocument` 和 Web/URL `UnifiedEvidence` 继续固定为：

```text
untrusted_content = true
instruction_authority = none
can_trigger_tool = false
can_change_tool_risk = false
can_approve = false
```

正文仍完整保存在 `snippet`、`content` 和 Unified Evidence 中，便于引用和审计。
检测代码写入 `detected_untrusted_patterns`，不产生新的 Evidence 模型。

### URL Fetch 与 SSRF

保留并验证 V5.1 的安全链路：

- 只允许 HTTP/HTTPS；
- 禁止 URL 用户名和密码；
- 只允许 80/443；
- 禁止 localhost、私网、回环、链路本地和非 global IP；
- DNS 全部解析结果必须为公网 IP；
- Transport 连接到已验证 IP，保留 Host/TLS SNI，防止 DNS rebinding；
- 每次重定向重新执行完整 URL 和 DNS 校验；
- 限制重定向次数、响应大小、超时、Content-Type 和 Content-Encoding。

V5.4 额外加入常见云 metadata hostname 显式拒绝规则；metadata IP
`169.254.169.254` 继续由非公网 IP 规则阻止。

### Tool Risk Policy

`retrieve_web` 和内部 `url_fetch` 被显式归类为 `MEDIUM`。它们仍是只读操作，
默认可以执行，但必须经过现有 Safety Policy；网页内容无法把风险降为 LOW、改变
Tool Scope 或授予自身执行权限。

Source Router Tool Boundary 保持不变。`LOCAL` 策略下的 Web Tool 越界调用在
handler 执行前由程序拒绝。

### Trace 与隐私

Web Tool Trace 增加：

- `search_query`；
- `source_strategy`；
- `url`；
- `fetch_status`；
- `latency_ms`；
- `evidence_count`；
- `detected_untrusted_patterns`。

Agent 普通执行、Workflow 执行和 V5.3 Cross-Source Trace 均可携带这些字段。
Trace 仍不记录模型内部推理或网页完整正文。查询中的手机号、邮箱、身份证和地址
继续使用统一 Redaction；URL 中 token、key、password、secret、session、signature
等敏感查询参数会被遮蔽。

## 3. 修改模块

- `backend/services/web_safety.py`
  - 新增 Web 内容风险模式和只读安全评估。
- `backend/services/web_models.py`
  - Web Record 增加 `untrusted_content` 和检测标记；不改变 Evidence Schema。
- `backend/services/web_page_parser.py`
  - 解析后标记正文风险，保留原文。
- `backend/services/search_provider.py`
  - Provider 结果归一化时标记标题和摘要风险。
- `backend/evidence.py`
  - 将已有检测标记带入 Unified Evidence 已有字段和 metadata。
- `backend/services/url_fetch.py`
  - 增加云 metadata hostname 显式拒绝规则。
- `backend/runtime/safety_policy.py`
  - Web Tool 加入明确的 MEDIUM 风险分类。
- `backend/services/redaction.py`
  - 增加敏感 URL 查询参数 Trace 脱敏。
- `backend/services/trace_service.py`
  - 增加统一 Web Trace 指标。
- `backend/runtime/task_runner.py`、`backend/agent.py`
  - 将 Source Strategy 等 Web 指标传入普通与 Workflow Trace。
- `backend/services/cross_source_retrieval.py`
  - V5.3 每轮 Trace 补充相同的 Web 可观测字段；检索算法不变。
- `backend/services/evaluation_service.py`
  - 增加 `web_safety` 聚合指标。

## 5. 限制

- Prompt Injection 检测是确定性风险标记，不是内容真实性判断，也不会删除正文。
- 模式检测无法识别所有自然语言变体；真正的安全边界仍是程序级 Tool Registry、
  Source Tool Scope、参数 Schema、Risk Policy 和审批机制。
- 通用 Search Provider 仍由部署方配置；测试不访问实时互联网。
- 本阶段没有增加 Retrieval 算法、Evidence 模型、Source Router、Multi Agent、
  Graph RAG、长期 Agent 或前端功能。
