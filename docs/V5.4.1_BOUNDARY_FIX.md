# V5.4.1 模块边界修正

## 1. 问题

V5.4 的 Prompt Injection、SSRF、URL Safety、Tool Risk、Trace 和 Evaluation
功能测试全部通过，但安全实现直接修改了两个已经稳定的核心文件：

- `backend/services/cross_source_retrieval.py`；
- `backend/evidence.py`。

修改内容没有改变 V5.3 检索算法、Evidence Schema 或 Factory 结构，但违反了
V5.4 只能在 Security、Trace 和 Adapter 边界增量开发的严格要求。

## 2. 调整前架构

```text
CrossSourceRetrieval
    └── 自身写入 V5.4 Web Trace 字段

UnifiedEvidenceFactory / Web Evidence Builder
    └── 自身附加 Prompt Injection 检测字段
```

这使安全和可观测性逻辑进入了 V5.3、V5.2.1 的稳定核心模块。

## 3. 调整后架构

### Web Evidence 安全适配

```text
Web Parser / Search Provider
    ↓
Web Safety 检测和 Untrusted 标记
    ↓
稳定 UnifiedEvidenceFactory
    ↓
secure_web_evidence() Security Adapter
    ↓
WebRetrievalService 输出
```

`backend/evidence.py` 已恢复到 V5.2.1/V5.3 基线状态。Factory、Schema、
Serializer 和 Web Evidence Builder 均不包含 V5.4 安全逻辑。

`backend/services/web_safety.py` 的 `secure_web_evidence()` 在 Factory 边界之后，
使用已有 `UnifiedEvidence` 字段附加以下程序生成的安全属性：

- `metadata.untrusted_content=true`；
- `detected_untrusted_patterns`。

它不会创建新 Evidence 类型，也不会改变来源正文、Evidence ID、来源定位或
Authority/Freshness。

### Cross-Source Trace 适配

```text
稳定 CrossSourceRetrieval
    ↓ existing record_trace event
Trace Middleware
    ↓
Web Observability Metrics
```

`backend/services/cross_source_retrieval.py` 已恢复到 V5.3 提交状态。
通用 `backend/services/trace_service.py` 根据既有 `tool_name`、arguments、result、
duration 和调用方 metrics 补全 Web 可观测字段，不要求检索模块了解 V5.4。

## 4. 模块边界

以 V5.3 提交 `23af4fb` 为基准，以下稳定文件保持零差异：

- `backend/services/source_router.py`；
- `backend/services/tool_scope_resolver.py`；
- `backend/services/cross_source_retrieval.py`；
- `backend/evidence.py`。

因此以下核心边界未修改：

- Source Router；
- Tool Scope Resolver；
- Cross-Source Retrieval 算法、预算、循环和充分性判断；
- UnifiedEvidence Schema；
- UnifiedEvidenceFactory；
- Evidence 3.0 Compatibility Serializer。

V5.4 安全能力现在只位于：

- Security Layer：`web_safety.py`、`safety_policy.py`、`url_fetch.py`；
- Adapter Layer：`web_retrieval.py`、`web_page_parser.py`、`search_provider.py`；
- Trace Layer：`trace_service.py`、Agent/Workflow Trace 参数适配；
- Evaluation Layer：`evaluation_service.py` 和 V5.4 离线安全测试。
