## 问题与处理

1. 收起“更多”导致 Widget Key 清理、显示偏好丢失：用独立的展示偏好状态解决，并新增跨页回归用例。
2. 固定浅色侧栏/指标与深色主题冲突：移除固定配色，以继承前景色派生表面和边框。
3. 顶部栏可能被原生工具栏遮挡：为原生工具栏保留顶部间距，并通过真实截图检查。
4. 本地环境文件不在忽略规则：添加三种实际/常见文件名，确认 Git 忽略凭据文件。
5. 首轮自动化中的同名上传触发原“禁止覆盖”规则：使用唯一合成文件名，保留后端保护行为。
6. Streamlit 开关的透明原生 input 被可见 label 覆盖：自动化改为正常点击可见标签，并另测键盘操作，没有使用强制点击绕过。
7. Streamlit 重跑可能在自动化打开选择菜单后关闭菜单：脚本等待页面结束重跑，再执行下一步。
8. Streamlit 1.61 的主题入口已直接放在原生菜单：脚本按实际菜单操作，未增加或替换产品主题系统。
9. 原有 `use_container_width` 在当前 Streamlit 有弃用提示。本次保留已有调用契约，未进行无关全项目 API 替换；这不等同浏览器异常，后续升级时应独立处理。
